# Gramma: learn to read the Greek alphabet
Jetpack Compose app. Lessons teach letters, then read English-sounding words in Greek script.
Build: AGP 8.5.2, Kotlin 2.0.20, minSdk 26. Greek audio needs a Greek TTS voice on the phone.
Audio: run make-audio.sh in Termux to add mp3 clips to the zip; without them the app uses phone TTS.
